# Comparisons

How Ezenwa Grotesk was arrived at, built on Archivo.

- `base-candidates.png`: the open-licence fonts considered as a base.
- `aperture-candidates.png`: the letters that carry the intended character
  in Libre Franklin, Chivo and Archivo. Archivo's closed apertures made it
  the base.
- `full-ezenwa.png`, `full-archivo.png`: the same specimen in each font, at the
  same size.
- `letters-before.png`, `letters-after.png`: the f and t before and after
  their rebuild.
- `compare-roundness-overlay.png`: outlines before (red) and after (blue)
  rounding.
- `accents-and-italics.png`: accented Latin, Vietnamese, currency and figures
  in Regular, Italic, Bold and Bold Italic.
